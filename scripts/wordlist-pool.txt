# The candidate pool the login passphrase's word list is chosen from.
#
# This is input, not the list itself: src/sshd_hostkey.c holds the 1024 words the
# server actually draws from, and scripts/gen_wordlist.py decides which of these
# candidates may be among them and checks the properties that makes true. Nothing
# here reaches a binary; editing this file changes nothing until the array in the
# source is regenerated and re-checked.
#
# Shape rules a candidate must satisfy to be eligible (see the script for why):
# lowercase a-z only, three to nine letters, distinct, and not a prefix of another
# kept word. Words that fail are dropped with a count, not a fatal error, so a
# stray long word in the pool costs it its place and nothing else.
#
# Grouping is only for readability; the emitted list is shuffled deterministically
# so a passphrase is not "six animals in a row".
